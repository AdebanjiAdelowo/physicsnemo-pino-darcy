1. **Documentation consistency — addressed.** The original `docs/G8_TEST_EVALUATION_HANDOFF.md` is preserved as a historical handoff and now has a dated post-handoff addendum pointing to the completed nine-file verification. Checkpoint bundles and other unarchived manifest entries must not be presented as independently reverified.
2. **Numerical-method verification — partially supported.** Synthetic CPU tests support the finite-difference and discrete-operator implementation. The MATLAB generator comparison, 241-grid numerical accuracy, and GPU execution provenance were not independently reproduced by this review. A stronger independent check would compare fixed input/output vectors to the original generator, if those trusted reference vectors are already available; do not access or rerun the frozen test set.
3. **Holdout/selection — limitation retained.** G8 is a follow-up on an already examined test set. Validation-only reconstruction supports the recorded selection decisions; it does not make the test holdout untouched. The original frozen records must remain immutable.
4. **Scope — broad PR.** PR #1 changes more than the G8 archive, including training/evaluation code and historical experiment records. CI passing is not sufficient to approve the entire research branch. Review each major code/experiment family and provenance before marking ready.
5. **Reproducibility — bounded.** The available CI is CPU/offline and cannot establish bitwise full-length GPU retraining or every model-evaluation kernel's device. Avoid claiming these are verified.
