## Findings and remaining gates

Checkpoint bundles and other unarchived manifest entries must not be presented as independently reverified.
2. **Numerical-method verification — partially supported.** Synthetic CPU tests support the finite-difference and discrete-operator implementation. The MATLAB generator comparison, 241-grid numerical accuracy, and GPU execution provenance were not independently reproduced by this review. A stronger independent check would compare fixed input/output vectors to the original generator, if those trusted reference vectors are already available; do not access or rerun the frozen test set.
3. **Holdout/selection — limitation retained.** G8 is a follow-up on an already examined test set. Validation-only reconstruction supports the recorded selection decisions; it does not make the test holdout untouched. The original frozen records must remain immutable.
4. **Scope — broad PR.** PR #1 changes more than the G8 archive, including training/evaluation code and historical experiment records. CI passing is not sufficient to approve the entire research branch. Review each major code/experiment family and provenance before marking ready.
5. **Reproducibility — bounded.** The available CI is CPU/offline and cannot establish bitwise full-length GPU retraining or every model-evaluation kernel's device. Avoid claiming these are verified.

## Decision

Keep PR #1 **draft and unmerged** pending a complete review of the broader branch. No training, test-set re-evaluation, freeze alteration, or checkpoint replacement is authorized by this report.

## Training and evaluation code-path review (9 November 2026)

**Scope:** static source inspection of `scripts/train.py`, `src/pino_darcy/{study,engine,selection,freeze}.py`, `scripts/{evaluate_variants,regularisation_study}.py`, and `tests/test_regularisation_freeze.py`. No training, inference, dataset loading, or test evaluation was executed in this review.

- **Training data isolation:** `study.train_study` calls `engine.prepare_study(..., with_test=False)`. `engine.load_datasets` loads validation and training splits; the unlabelled pool, when enabled, is sliced from the training split and exposes permeability only. This supports separation for the inspected training entry point. `engine.load_datasets` itself defaults to `with_test=True`, so future training callers must continue to opt out explicitly.
- **Optimisation:** `selection.make_optimiser` selects Adam or AdamW from configuration; the code applies decoupled decay only for AdamW. The training loop uses one sample per optimizer step, a per-step exponential learning-rate scheduler, and a separate seeded permutation. No test metrics appear in the inspected optimizer update path.
- **Validation checkpoint decisions:** early-stopping trackers consume `validation_rel_l2` and snapshot the best model state; `early_stopping_outcome` reconstructs the same decision from validation histories. The study's weight-decay selection reads validation variant records. The stored `test_set_read: false` field is inaccurate as a literal access claim and remains qualified by F19; do not change the immutable selection JSON.
- **Test evaluation gate:** `evaluate_variants.evaluate(stage='test')` invokes `freeze.check_restore` **before** `engine.prepare_study`. `study.evaluate_study` invokes `selection.guard_test_evaluation` before loading test tensors. The freeze tests exercise tampering of the selection, receipt, checkpoint, configuration, and dataset before data preparation. These checks cover the inspected standard entry points, not arbitrary future code paths.
- **Reporting:** `regularisation_study.analyse` computes paired comparisons from the archived per-variant records after selection; this review has not independently recomputed every published table from the original JSON bytes.

**Review outcome:** no new blocking implementation defect identified in these inspected paths. Remaining work: independent archive-only numerical/statistical reconciliation, provenance review of other experiment families and scripts, and explicit acknowledgement that source inspection and CPU CI do not prove independent GPU replication. Keep the PR draft.
